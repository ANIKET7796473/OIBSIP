# Retail Sales EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales trends, customer behavior, product performance, and actionable business insights.

## Objective

- Analyze retail sales data
- Clean and prepare the dataset
- Identify sales trends
- Analyze customer demographics
- Identify top-performing products
- Analyze revenue by category
- Find correlations between numerical variables
- Provide actionable business recommendations

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
